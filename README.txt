SISTEMA DE GESTIÓN DE CITAS MÉDICAS

Proyecto desarrollado para la evidencia:
GA7-220501096-AA3-EV01

DESCRIPCIÓN:
Aplicación web desarrollada en Java Web utilizando JSP, Servlets,
Bootstrap y MySQL, enfocada en la gestión de citas médicas.

FUNCIONALIDADES:
- Registro de usuarios
- Inicio de sesión
- Registro de citas médicas
- Validaciones de formularios
- Conexión a base de datos

TECNOLOGÍAS UTILIZADAS:
- Java
- JSP
- Servlets
- Bootstrap
- MySQL
- Apache NetBeans
- GitHub

REQUISITOS:
- JDK 17 o superior
- Apache Tomcat
- MySQL
- NetBeans IDE

INSTRUCCIONES DE EJECUCIÓN:
1. Importar el proyecto en NetBeans.
2. Configurar la base de datos MySQL.
3. Ejecutar el servidor Apache Tomcat.
4. Iniciar el proyecto.
